# 校区综合客服 AI 工具

## 简介
校区综合客服数据整理一站式工具，整合教材差异表、教材签收表、新生书包领取表、考勤表转换、VOC业绩分析五大工具，纯前端运行，数据本地处理，安全可靠。

## 在线访问
部署完成后，通过 Netlify 生成的链接访问，无需下载任何文件。

## 工具清单
| 模块 | 工具 |
|------|------|
| 开课工作 | 自动制作教材差异表、自动制作教材签收表、自动制作新生书包领取表 |
| 日常工作 | PNG班表转换考勤表 |
| VOC工作 | VOC电话访谈业绩分析 |

## 更新方式
在 GitHub 仓库页面上传新版 `index.html`，Netlify 将自动完成部署更新（通常 1 分钟内生效）。
